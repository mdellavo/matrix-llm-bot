# !dm map assets

Compiled into the bot by `src/dm/sprites.rs`, which draws `!dm` maps from them. Each is
the pack's packed sheet of 16×16 tiles, unchanged. All three are CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/), so credit isn't required, but it's
given here anyway.

- `tiny-town.png`: Tiny Town 1.1 by Kenney (https://kenney.nl/assets/tiny-town), CC0.
- `tiny-dungeon.png`: Tiny Dungeon 1.0 by Kenney (https://kenney.nl/assets/tiny-dungeon),
  CC0.
- `tiny-creatures.png`: Tiny Creatures 1.0 by Clint Bellanger
  (https://clintbellanger.itch.io/tiny-creatures), an expansion of Kenney's two packs, CC0.

Neither pack has water or mountains, so those, darkness, and magical glows are drawn in code.
